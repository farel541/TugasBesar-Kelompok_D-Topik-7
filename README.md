# TugasBesar-Kelompok_D-Topik-7
Deskripsi Aplikasi pengelolaan komunitas kampus (ukm.telu) mencatat mahasiswa dan komunitas yang diikuti. Seorang mahasiswa dapat bergabung dengan beberapa komunitas dan setiap komunitas dapat memiliki banyak anggota. Setiap anggota dapat mengikuti berbagai kegiatan komunitas dan memperoleh poin keaktifan.
